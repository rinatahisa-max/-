# Правум Frontend

Frontend-проект LegalTech-платформы «Правум» на Next.js, React, TypeScript и Tailwind CSS.

## Основные маршруты

- `/` — главная страница с Hero, модулями продукта, StatusSyncBlock, AI, маркетплейсом, тарифами и FAQ.
- `/clients`, `/lawyers`, `/law-firms`, `/business` — страницы аудиторий.
- `/ai`, `/marketplace`, `/features`, `/pricing` — продуктовые страницы.
- `/contacts`, `/login`, `/register` — формы с frontend-валидацией и состоянием успешной отправки.
- `/privacy`, `/terms`, `/personal-data` — правовые страницы.

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run typecheck
npm run lint
npm run build
```
